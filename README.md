# Praneshwaran — Professional Portfolio

A deliberately minimal, editorial-style portfolio for an AI & Data Science engineering graduate.

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite.

## Before deployment

Replace:
- `public/resume.pdf` with the real resume PDF.
- GitHub/LinkedIn links in `src/main.jsx`.
- Email address in `src/main.jsx`.
- Any project details that need correction.

The design intentionally avoids generic "AI portfolio" effects: no gradients, glassmorphism, particle backgrounds, or excessive animation.
